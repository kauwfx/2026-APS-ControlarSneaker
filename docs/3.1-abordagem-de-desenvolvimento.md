# 3.1 Abordagem de Desenvolvimento
O ControlarSneaker é desenvolvido de forma iterativa e incremental. Cada ciclo produz uma seção deste documento na ordem definida pela análise: inicia-se com a definição do sistema (4.1), segue para os requisitos e casos de uso (4.2.1 e 4.2.2), passa para a estrutura interna de dados (4.2.3), comportamento e sequência (4.2.5 e 4.2.4), persistência (4.2.6), interface com o usuário (4.2.7) e encerra-se com a arquitetura (3.3).

Ao término de cada ciclo, a seção gerada é conferida contra as anteriores para garantir a rastreabilidade entre requisitos, casos de uso e dados do sistema. As correções necessárias são aplicadas diretamente no arquivo de origem e versionadas no repositório GitHub.

Essa abordagem foi escolhida por permitir validar cada etapa incrementalmente antes de avançar, evitando erros tardios. Por se tratar de um desenvolvimento individual, as reuniões diárias do Scrum foram dispensadas, adotando-se o princípio de ciclos curtos com entregas revisáveis.
